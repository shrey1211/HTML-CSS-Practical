# Assignment 5 – Share the Pushed GitHub Repository Link as Proof of Setup

## Aim

To create a GitHub repository and share its link as proof that the repository has been successfully set up and pushed online.

## Objective

To learn how to connect a local Git repository to GitHub, upload project files, and share the repository link.

## Introduction

GitHub is an online platform used to store, manage, and share code repositories. Git helps track changes in project files, while GitHub allows the repository to be accessed online.

## Steps Performed

1. Created a repository on GitHub named `HTML-CSS-45-Assignments`.
2. Organized the assignment files into their respective module folders.
3. Initialized Git in the local project folder.
4. Added project files to Git and committed the changes.
5. Connected the local repository to the GitHub repository.
6. Pushed the committed files to GitHub.
7. Opened the repository on GitHub to verify that the files were uploaded successfully.

## Git Commands Used

```bash
git init
git add .
git commit -m "docs: add project files"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

**Note:** These commands are examples of the workflow. Run only the commands needed for your current repository, and replace `YOUR_GITHUB_REPOSITORY_URL` with your actual repository URL.
