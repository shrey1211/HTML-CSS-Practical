# Assingment 1: What Happens When Your Type a URL


When a user types a URL into a web browser, the browser identifies the website's address and uses DNS (Domain Name System) to find the server's IP address.The browser then sends an HTTP or HTTPS request to the server.The server processes the request and sends the necessary webpage files, such as HTML, CSS, and images, back to the browser.Finally, the browser reads these files, applies the styling, and displays the webpage on the screen.
