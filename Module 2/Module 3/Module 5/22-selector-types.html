Understanding CSS Selectors

1. Element Selector

The element selector styles all elements of a specified type. In this page, the body selector sets the font, background colour, text colour, and spacing for the entire page.

2. Class Selector

This paragraph uses the highlight class selector. A class selector begins with a dot (.) in CSS and can be applied to multiple HTML elements.

3. ID Selector

The main heading uses the ID selector. An ID selector begins with a hash symbol (#) and targets an element with a specific ID.

4. Descendant Selector

The CSS selector section p targets paragraph elements located inside a section element. It changes their font size and text colour.

5. Group Selector

One Rule for Multiple Elements

The group selector applies the same style to multiple selectors. Here, h2 and h3 headings share the same text colour.
