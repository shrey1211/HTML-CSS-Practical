Assignment 26 — Module 6

Aim

To understand and annotate the CSS box model by examining an element created using HTML and CSS.

Every HTML element is represented as a rectangular box consisting of content, padding, border, and margin.

My Own Element: Sample Card

The card below is the element selected for this assignment. Its CSS properties demonstrate the four parts of the box model.

My Sample Card

This is the content area of my element.

Annotations

1. Margin — 30px

The transparent outer space around the card. It separates the card from surrounding elements.

2. Border — 8px

The teal-coloured edge surrounding the card's padding and content.

3. Padding — 20px

The space between the content and the border. It gives the text room to breathe.

4. Content — 250px wide

The innermost area containing the heading and paragraph. The specified content width is 250px.

Conclusion

The CSS box model helps control the size, spacing, and appearance of HTML elements. Understanding these four layers makes webpage layouts easier to design.
