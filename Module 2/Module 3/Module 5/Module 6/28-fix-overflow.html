How the Overflow Was Fixed

1. box-sizing: border-box;
Includes padding and borders within an element's specified width.

2. flex-wrap: wrap;
Allows cards to move onto another line when space is limited.

3. min-width: 0;
Allows flex items to shrink within their available space.

4. overflow-wrap: anywhere;
Allows very long words to break rather than extend outside a card.

5. max-width: 100%;
Prevents images from becoming wider than their containers.

Important CSS Used

* {
    box-sizing: border-box;
}

.card-container {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1 1 220px;
    min-width: 0;
}

.card p {
    overflow-wrap: anywhere;
}

img {
    max-width: 100%;
    height: auto;
}
