Design Choices

Colour palette: Navy blue creates a professional appearance, while teal highlights buttons and important elements. Light grey-blue provides a calm background.

Font pairing: Georgia is used for headings to create visual contrast. Arial is used for body text because it is simple and readable.

Layout: Cards, consistent spacing, rounded corners, and clear headings make the content easy to follow.

Navigation: The navigation bar links directly to the Home, About, Registration, and Contact sections within this file.

Responsive design: A media query adjusts the layout and navigation for smaller screens.

Conclusion: This project demonstrates how HTML and CSS can create a consistent, attractive, and responsive website design.
