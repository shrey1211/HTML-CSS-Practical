# Assignment 3: Terminal Navigation Practice Sheet

## Aim
To practise basic terminal commands for navigating folders, checking the current directory, listing files, and creating directories.

## Software Used
- Visual Studio Code (VS Code)
- Git Bash or Command Prompt (CMD)

## Terminal Navigation Commands

| S. No. | Command | Purpose | Example |
|---|---|---|---|
| 1 | `pwd` | Displays the current working directory. | `pwd` |
| 2 | `ls` | Lists files and folders in the current directory. | `ls` |
| 3 | `cd foldername` | Moves into a specified folder. | `cd Documents` |
| 4 | `cd ..` | Moves one level up to the parent folder. | `cd ..` |
| 5 | `mkdir foldername` | Creates a new folder. | `mkdir Practice` |
| 6 | `clear` | Clears the terminal screen. | `clear` |
| 7 | `ls -a` | Displays all files, including hidden files, on Git Bash or a Unix-like terminal. | `ls -a` |
| 8 | `cd ~` | Moves to the user's home directory in Git Bash or a Unix-like terminal. | `cd ~` |

## Practice Activity

The following commands were used to practise terminal navigation:

```bash
pwd
ls
mkdir TerminalPractice
cd TerminalPractice
pwd
cd ..
ls
```

## Expected Result

1. The current directory is displayed.
2. The files and folders in the current directory are listed.
3. A new folder named `TerminalPractice` is created.
4. The terminal moves into the new folder.
5. The current directory is checked again.
6. The terminal returns to the parent folder.
7. The files and folders are listed again.

## Conclusion

This practice sheet covers basic terminal-navigation commands. These commands help users move between directories, view files and folders, create directories, and manage project files efficiently.
